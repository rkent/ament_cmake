ament_cmake_test.ament_add_test¶

ament_cmake_test.ament_add_test.ament_add_test(testname **kwargs)¶

Add a test.

A test is expected to generate a JUnit result file ${AMENT_TEST_RESULTS_DIR}/$PROJECT_NAME}/${testname}.xml. Failing to do so is considered a failed test.

Parameters:

  • testname (string) – the name of the test

  • COMMAND (list of strings) – the command including its arguments to invoke

  • OUTPUT_FILE (string) – the path of the file to pipe the output to

  • RUNNER (string) – the path to the test runner script (default: run_test.py).

  • TIMEOUT (integer) – the test timeout in seconds, default: 60

  • WORKING_DIRECTORY (string) – the working directory for invoking the command in, default: CMAKE_CURRENT_BINARY_DIR

  • GENERATE_RESULT_FOR_RETURN_CODE_ZERO (option) – generate a test result file when the command invocation returns with code zero command in, default: FALSE

  • SKIP_TEST (option) – if set mark the test as being skipped

  • ENV (list of strings) – list of env vars to set; listed as VAR=value

  • APPEND_ENV (list of strings) – list of env vars to append if already set, otherwise set; listed as VAR=value

  • APPEND_LIBRARY_DIRS (list of strings) – list of library dirs to append to the appropriate OS specific env var, a la LD_LIBRARY_PATH

  • SKIP_RETURN_CODE (integer) – return code signifying that the test has been skipped and did not fail OR succeed

@public

"${testname}"(COMMAND ${cmd_wrapper} WORKING_DIRECTORY "${ARG_WORKING_DIRECTORY}")

Warning

This is a CTest test definition, do not call this manually. Use the “ctest” program to execute this test.
