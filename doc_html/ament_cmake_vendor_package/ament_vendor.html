ament_cmake_vendor_package.ament_vendor¶

ament_cmake_vendor_package.ament_vendor.ament_vendor(TARGET_NAME **kwargs)¶

Note

This is a macro, and so does not introduce a new scope.

Build and install an external project as a vendor package.

Parameters:

  • TARGET_NAME (string) – the name to give this vendor package target.

  • SATISFIED (option) – a boolean flag indicating whether there is a system package which already satisfies the requirement that this vendor package aims to provide.

  • VCS_TYPE (string) – the mechanism used to fetch the project source code (i.e. git, tar, zip, svn, path). Defaults to ‘git’ if not specified.

  • VCS_URL (string) – the VCS-specific URL to fetch the project source code from.

  • VCS_VERSION (string) – the VCS-specific version to fetch the projcect source code at.

  • PATCHES (list of strings) – paths to patch files to apply to downloaded source code, either absolute or relative to the current calling directory. If given a directory, all patch files in the directory (non-recursive) will be applied in alphabetical order.

  • CMAKE_ARGS (list of strings) – extra arguments to pass to the CMake invocation of the external project.

  • SOURCE_SUBDIR (string) – subdirectory within the external project to be built and installed. Defaults to the root directory.

  • SKIP_INSTALL (option) – when specified, do not install the external project or any associated ament support files.

  • GLOBAL_HOOK (option) – rather than requiring consumers of the external project to find_package the vendor package prior to looking for the external project, expose the external project globally to any downstream CMake projects.

@public

ament_cmake_vendor_package.ament_vendor.FORCE_BUILD_VENDOR_PKG¶

Note

This variable is a user-editable option, meaning it appears within the cache and can be edited on the command line by the -D flag.

Help text:

“Build vendor packages from source, even if system-installed packages are available”

Default value:

OFF

Type:

bool
