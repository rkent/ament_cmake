ament_cmake_core.index/ament_index_get_resources¶

ament_cmake_core.index/ament_index_get_resources.ament_index_get_resources(var resource_type **kwargs)¶

Get all registered package resources of a specific type from the index.

Parameters:

  • var (list of resource names) – the output variable name

  • resource_type (string) – the type of the resource

  • PREFIX_PATH (list of strings) – the prefix path to search for (default ament_index_get_prefix_path()).
