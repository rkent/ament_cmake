ament_cmake_pytest.ament_add_pytest_test¶

ament_cmake_pytest.ament_add_pytest_test.ament_add_pytest_test(testname path **kwargs)¶

Add a pytest test.

Parameters:

  • testname (string) – the name of the test

  • path (string) – the path to a file or folder where pytest should be invoked on

  • NOCAPTURE (option) – disable pytest output capturing. Sets the pytest option ‘-s’.

  • SKIP_TEST (option) – if set mark the test as being skipped

  • PYTHON_EXECUTABLE (string) – Python executable used to run the test. It defaults to the CMake executable target Python3::Interpreter.

  • RUNNER (string) – the path to the test runner script (default: see ament_add_test).

  • TIMEOUT (integer) – the test timeout in seconds, default defined by ament_add_test()

  • WERROR (bool) – If ON, then treat warnings as errors. Default: OFF.

  • WORKING_DIRECTORY (string) – the working directory for invoking the command in, default defined by ament_add_test()

  • ENV (list of strings) – list of env vars to set; listed as VAR=value

  • APPEND_ENV (list of strings) – list of env vars to append if already set, otherwise set; listed as VAR=value

  • APPEND_LIBRARY_DIRS (list of strings) – list of library dirs to append to the appropriate OS specific env var, a la LD_LIBRARY_PATH

@public

ament_cmake_pytest.ament_add_pytest_test.AMENT_CMAKE_PYTEST_WITH_COVERAGE¶

Note

This variable is a user-editable option, meaning it appears within the cache and can be edited on the command line by the -D flag.
