ament_cmake_auto.ament_auto_add_gmock¶

ament_cmake_auto.ament_auto_add_gmock.ament_auto_add_gmock(target **kwargs)¶

Note

This is a macro, and so does not introduce a new scope.

Add a gmock with all found test dependencies.

Call add_gmock(target ARGN), link it against the gmock libraries and all found test dependencies.

If gmock is not available the specified target is not being created and therefore the target existence should be checked before being used.

Parameters:

  • target (string) – the target name which will also be used as the test name

  • ARGN (list of strings) – the list of source files and parameters

@public

ament_cmake
