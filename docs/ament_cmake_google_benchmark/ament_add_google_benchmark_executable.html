ament_cmake_google_benchmark.ament_add_google_benchmark_executable¶

ament_cmake_google_benchmark.ament_add_google_benchmark_executable.ament_add_google_benchmark_executable(target)¶

Note

This is a macro, and so does not introduce a new scope.

Add an executable using google benchmark.

Call add_executable(target ARGN) and link it against the google benchmark libraries. It does not register the executable as a test.

If google benchmark is not available the specified target is not being created and therefore the target existence should be checked before being used.

Parameters:

  • target (string) – the target name which will also be used as the test name

  • ARGN (list of strings) – the list of source files

  • SKIP_LINKING_MAIN_LIBRARIES (option) – if set skip linking against the google benchmark main libraries
