ament_add_google_benchmark_test

ament_cmake_google_benchmark.ament_add_google_benchmark_test.ament_add_google_benchmark_test(target **kwargs)

Add an existing executable using google benchmark as a test.

Register an executable created with ament_add_google_benchmark_executable() as a test. If the specified target does not exist the registration is skipped.

Parameters:

  • target (string) – the target name which will also be used as the test name

  • RUNNER (string) – the path to the test runner script (default: see ament_add_test).

  • TIMEOUT (integer) – the test timeout in seconds, default defined by ament_add_test()

  • WORKING_DIRECTORY (string) – the working directory for invoking the executable in, default defined by ament_add_test()

  • RUN_PARALLEL (option) – if set allow the test to be run in parallel with other tests

  • SKIP_TEST (option) – if set mark the test as being skipped

  • ENV (list of strings) – list of env vars to set; listed as VAR=value

  • APPEND_ENV (list of strings) – list of env vars to append if already set, otherwise set; listed as VAR=value

  • APPEND_LIBRARY_DIRS (list of strings) – list of library dirs to append to the appropriate OS specific env var, a la LD_LIBRARY_PATH
