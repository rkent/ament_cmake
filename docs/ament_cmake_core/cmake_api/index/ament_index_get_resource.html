ament_index_get_resource

ament_cmake_core.index/ament_index_get_resource.ament_index_get_resource(var resource_type resource_name **kwargs)

Get the content of a specific resource from the index.

Parameters:

  • var (string) – the output variable name for the content of the requested resource

  • resource_type (string) – the type of the resource

  • resource_name (string) – the name of the resource

  • PREFIX_PATH (list of strings) – the prefix path to search for (default ament_index_get_prefix_path()).
